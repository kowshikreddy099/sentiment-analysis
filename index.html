About the project

The full Python project includes a BiLSTM trained from scratch and a fine-tuned transformer (DistilBERT / RoBERTa / DeBERTa-v3) trained on a mix of Amazon, Yelp and IMDb reviews, plus a Gradio web app.

This page uses the public checkpoint distilbert-base-uncased-finetuned-sst-2-english, the same default model the Python app loads.

Run the Python app locally (Windows)

git clone https://github.com/kowshikreddy099/sentiment-analysis.git
cd sentiment-analysis\sentiment-analysis
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:7860
