Review Sentiment Analysis

Classify English movie, product, and service reviews as positive or negative with a Python application using Transformers and an optional BiLSTM model.

View source codeRead project documentation

Application status

This is the project's GitHub Pages homepage. The Python sentiment analyzer does not run on GitHub Pages. No separate hosted analyzer link is configured here.

The local app uses a pretrained DistilBERT checkpoint unless a custom model is supplied. Custom training and measured accuracy are not claimed.

Run locally on Windows

git clone https://github.com/kowshikreddy099/sentiment-analysis.git
cd sentiment-analysis/sentiment-analysis
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py

Open the local address printed in the terminal, normally http://127.0.0.1:7860.

Host the working analyzer

Create a public Gradio Space on Hugging Face. Upload app.py, requirements.txt, and src/ from the inner sentiment-analysis folder. Keep the Space's generated README settings. When the Space is Running, test a review and copy its public link.
